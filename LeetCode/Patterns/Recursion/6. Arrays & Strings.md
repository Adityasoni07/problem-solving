# 6. Arrays & Strings — Recursion

> **Goal:** Learn how to apply recursion to arrays and strings by thinking in terms of **index/state + smaller remaining problem**, instead of treating the entire array/string as one big problem.

---

# 1. Why Arrays & Strings With Recursion?

Most recursion problems on arrays and strings follow a simple idea:

```text
Current position
      ↓
Do something with current element
      ↓
Move to the smaller remaining part
      ↓
Recursive call
```

For an array:

```text
[10, 20, 30, 40, 50]
  ↑
index
```

After processing index `0`:

```text
[10, 20, 30, 40, 50]
      ↑
    index 1
```

The recursive state is often:

```text
index
```

For strings:

```text
"hello"
  ↑
 index
```

or:

```text
left ----- right
```

depending on the problem.

---

# 2. The Most Important Function Definition

Before writing recursive code, define what your function means.

For example:

```java
solve(arr, index)
```

should have a clear meaning:

> **`solve(arr, index)` solves the problem for the array starting from `index`.**

Then:

```text
solve(arr, 0)
```

means:

```text
Solve the entire array.
```

and:

```text
solve(arr, 1)
```

means:

```text
Solve everything from index 1 onward.
```

This makes recursion much easier to reason about.

# 3. Basic Array Traversal

Example:

```java
void print(int[] arr, int index) {

    if (index == arr.length) {
        return;
    }

    System.out.println(arr[index]);

    print(arr, index + 1);
}
```

Call:

```java
print(arr, 0);
```

For:

```text
[10, 20, 30, 40]
```

calls:

```text
print(0)
   ↓
print(1)
   ↓
print(2)
   ↓
print(3)
   ↓
print(4)
   ↓
return
```

Output:

```text
10
20
30
40
```

---

# 4. How to Think About Array Recursion

Don't think:

> "I need to process the entire array."

Think:

> **"I only need to process the current index. Recursion will process the rest."**

For:

```text
[10, 20, 30, 40]
```

At index `0`:

```text
I handle 10.
Recursion handles [20, 30, 40].
```

At index `1`:

```text
I handle 20.
Recursion handles [30, 40].
```

And so on.

This is the most important mental model for recursive array problems.

# 5. Print Array in Reverse

Normal:

```java
void print(int[] arr, int index) {

    if (index == arr.length) {
        return;
    }

    System.out.println(arr[index]);

    print(arr, index + 1);
}
```

Reverse:

```java
void printReverse(int[] arr, int index) {

    if (index == arr.length) {
        return;
    }

    printReverse(arr, index + 1);

    System.out.println(arr[index]);
}
```

For:

```text
[10, 20, 30]
```

Output:

```text
30
20
10
```

Why?

Because printing happens **after** the recursive call.

```text
GO DOWN
   ↓
index 0
   ↓
index 1
   ↓
index 2
   ↓
base case
   ↓
COME BACK
   ↓
print 30
   ↓
print 20
   ↓
print 10
```

# 6. Find Sum of Array

Problem:

```text
[2, 5, 7, 3]
```

Think:

```text
sum(index)
=
arr[index] + sum(index + 1)
```

Code:

```java
int sum(int[] arr, int index) {

    if (index == arr.length) {
        return 0;
    }

    return arr[index] + sum(arr, index + 1);
}
```

For:

```text
sum(0)
```

thinking:

```text
2 + sum(1)
    ↓
    5 + sum(2)
        ↓
        7 + sum(3)
            ↓
            3 + sum(4)
                ↓
                0
```

Return:

```text
3
↑
7 + 3 = 10
↑
5 + 10 = 15
↑
2 + 15 = 17
```

Answer:

```text
17
```

---

# 7. Find Maximum Element

Function meaning:

> `max(arr, index)` returns the maximum element from `index` to the end.

Code:

```java
int max(int[] arr, int index) {

    if (index == arr.length - 1) {
        return arr[index];
    }

    int smallerAnswer = max(arr, index + 1);

    return Math.max(arr[index], smallerAnswer);
}
```

Thinking:

```text
max(index)
=
max(
    current element,
    maximum of remaining array
)
```

For:

```text
[4, 8, 2, 9, 3]
```

```text
max(0)
=
max(4, max(1))

max(1)
=
max(8, max(2))

...
```

Eventually:

```text
max(3)
=
max(9, max(4))
```

returns:

```text
9
```

Then the answer travels back upward.

---

# 8. Find Minimum Element

Same pattern:

```java
int min(int[] arr, int index) {

    if (index == arr.length - 1) {
        return arr[index];
    }

    int smallerAnswer = min(arr, index + 1);

    return Math.min(arr[index], smallerAnswer);
}
```

The structure is identical to maximum.

Only the combination changes:

```text
Maximum:
max(current, smallerAnswer)

Minimum:
min(current, smallerAnswer)
```

This is an important recursion pattern:

> **Recursive structure can stay the same while only the combine operation changes.**

# 9. Check If Array Is Sorted

Suppose:

```text
[1, 3, 5, 7, 9]
```

We need to check:

```text
arr[0] <= arr[1]
arr[1] <= arr[2]
arr[2] <= arr[3]
...
```

Recursive thinking:

```text
Current pair is sorted
AND
rest of array is sorted
```

Code:

```java
boolean isSorted(int[] arr, int index) {

    if (index == arr.length - 1) {
        return true;
    }

    if (arr[index] > arr[index + 1]) {
        return false;
    }

    return isSorted(arr, index + 1);
}
```

Function meaning:

> **`isSorted(arr, index)` means the array from `index` onward is sorted.**

---

# 10. Search for an Element

Problem:

```text
arr = [4, 7, 2, 9]
target = 2
```

Think:

```text
Is current element the target?
        |
       YES → true
        |
       NO
        ↓
Search the rest of the array.
```

Code:

```java
boolean contains(int[] arr, int index, int target) {

    if (index == arr.length) {
        return false;
    }

    if (arr[index] == target) {
        return true;
    }

    return contains(arr, index + 1, target);
}
```

---

# 11. Find First Occurrence

```java
int firstOccurrence(int[] arr, int index, int target) {

    if (index == arr.length) {
        return -1;
    }

    if (arr[index] == target) {
        return index;
    }

    return firstOccurrence(arr, index + 1, target);
}
```

Thinking:

```text
Check current index.
       ↓
Found?
 /     \
YES     NO
 ↓       ↓
return  search rest
```

Because we check from left to right, the first match is automatically returned.

---

# 12. Find Last Occurrence

Now the thinking changes.

We want the **last** occurrence.

So let recursion search the rest first:

```java
int lastOccurrence(int[] arr, int index, int target) {

    if (index == arr.length) {
        return -1;
    }

    int answer = lastOccurrence(arr, index + 1, target);

    if (answer != -1) {
        return answer;
    }

    if (arr[index] == target) {
        return index;
    }

    return -1;
}
```

Why?

Because:

```text
recursive call
    ↓
searches everything to the right
    ↓
if found → return that answer
    ↓
otherwise check current index
```

This is a great example of **return-phase thinking**.

---

# 13. Count Occurrences

Problem:

```text
arr = [2, 5, 2, 7, 2]
target = 2
```

Answer:

```text
3
```

Think:

```text
count(index)
=
current match
+
count(index + 1)
```

Code:

```java
int count(int[] arr, int index, int target) {

    if (index == arr.length) {
        return 0;
    }

    int current = (arr[index] == target) ? 1 : 0;

    return current + count(arr, index + 1, target);
}
```

# 14. Reverse an Array

There are two common ways to think about reversing.

## Method 1 — Two Pointers

Use:

```text
left
right
```

At every step:

```text
swap arr[left] and arr[right]
```

Then:

```text
left++
right--
```

Code:

```java
void reverse(int[] arr, int left, int right) {

    if (left >= right) {
        return;
    }

    int temp = arr[left];
    arr[left] = arr[right];
    arr[right] = temp;

    reverse(arr, left + 1, right - 1);
}
```

For:

```text
[1, 2, 3, 4, 5]
```

states:

```text
[1, 2, 3, 4, 5]
 ↑           ↑
 L           R

[5, 2, 3, 4, 1]
    ↑     ↑
    L     R

[5, 4, 3, 2, 1]
       ↑
       L/R
```

---

# 15. Array Recursion Patterns

Most array recursion problems fall into these patterns:

```text
1. Traversal
   index → index + 1

2. Accumulation
   current + smaller answer

3. Search
   check current → search rest

4. Comparison
   current vs recursive answer

5. Two pointers
   left++, right--

6. Return-phase processing
   recursive call first → process current while returning
```

Recognizing the pattern is more important than memorizing individual solutions.

# 17. Reverse a String

```java
void reverse(String s, int index) {

    if (index == s.length()) {
        return;
    }

    reverse(s, index + 1);

    System.out.println(s.charAt(index));
}
```

Output:

```text

e

```

Again:

```text
recursive call first
      ↓
return phase
      ↓
process current character
```

# 18. Check Palindrome

Example:

```text
"madam"
```

Compare:

```text
m == m
a == a
d == d
```

Then stop.

Recursive definition:

```text
palindrome(left, right)
=
current pair matches
AND
inner substring is palindrome
```

Code:

```java
boolean isPalindrome(String s, int left, int right) {

    if (left >= right) {
        return true;
    }

    if (s.charAt(left) != s.charAt(right)) {
        return false;
    }

    return isPalindrome(s, left + 1, right - 1);
}
```

State:

```text
[left, right]
      ↓
[left+1, right-1]
      ↓
[left+2, right-2]
```

---

# 19. Why Two Pointers Are Natural for Strings

For a palindrome:

```text
m a d a m
↑       ↑
L       R
```

After comparing:

```text
m == m
```

we don't need those characters anymore.

So:

```text
L++
R--
```

Now:

```text
m a d a m
  ↑   ↑
  L   R
```

This is a general recursive idea:

> **When the outer part is solved, recursively solve the inner part.**

# 20. Remove a Character

Suppose:

```text
s = "banana"
remove = 'a'
```

Result:

```text
"bnn"
```

One recursive approach:

```java
String removeChar(String s, int index, char target) {

    if (index == s.length()) {
        return "";
    }

    char current = s.charAt(index);

    String rest = removeChar(s, index + 1, target);

    if (current == target) {
        return rest;
    }

    return current + rest;
}
```

Thinking:

```text
Current character
      ↓
Is it target?
 /          \
YES          NO
 |            |
skip it      keep it
 \            /
   rest of string
```

# 21. Check If Two Strings Are Equal

A simple recursive comparison:

```java
boolean equal(String a, String b, int index) {

    if (index == a.length()) {
        return true;
    }

    if (a.charAt(index) != b.charAt(index)) {
        return false;
    }

    return equal(a, b, index + 1);
}
```

In practice, Java provides:

```java
a.equals(b)
```

so this is mainly a **recursion exercise**.

# 22. String → Character Decisions

A lot of later recursion problems involve making decisions for each character.

For example:

```text
String:
"abc"

At 'a':
    take
    skip

At 'b':
    take
    skip

At 'c':
    take
    skip
```

This creates:

```text
                 ""
              /      \
             a        ""
           /   \     /   \
         ab    a     b    ""
        ...
```

This is where:

```text
Arrays & Strings
       ↓
Recursive traversal
       ↓
Decision recursion
       ↓
```

# 23. Index-Based vs Two-Pointer Recursion

A very useful distinction:

## One Index

Use when processing from one direction:

```java
solve(index)
```

Examples:

- Print array
- Sum array
- Search
- Count
- Maximum
- Minimum
- String traversal

---

## Two Indices

Use when processing from both ends:

```java
solve(left, right)
```

Examples:

- Reverse array
- Palindrome
- Compare both ends

---

## Multiple State Variables

Sometimes the state requires more information:

```java
solve(index, currentSum)
```

or:

```java
solve(index, path)
```

This becomes increasingly important in backtracking and DP.

---

# 24. Function Meaning Is Everything

Before solving:

```java
solve(arr, index)
```

write:

```text
solve(arr, index)
=
solve the problem from index to the end.
```

For:

```java
solve(s, left, right)
```

write:

```text
solve(s, left, right)
=
solve the problem inside [left, right].
```

This prevents a huge amount of recursion confusion.

# 25. Common Array/String Recursion Template

## One Index

```java
ReturnType solve(int[] arr, int index) {

    if (baseCase) {
        return baseAnswer;
    }

    // Current element

    return solve(arr, index + 1);
}
```

---

## Two Indices

```java
ReturnType solve(int[] arr, int left, int right) {

    if (baseCase) {
        return baseAnswer;
    }

    // Current pair

    return solve(arr, left + 1, right - 1);
}
```

# 26. Complexity

For one-index traversal:

```text
index
 ↓
index + 1
 ↓
index + 2
...
```

Number of calls:

```text
O(N)
```

Time:

```text
O(N)
```

assuming `O(1)` work per call.

Stack space:

```text
O(N)
```

---

For two-pointer recursion:

```text
left++
right--
```

both move toward each other.

Number of calls:

```text
N/2
```

which is still:

```text
O(N)
```

So:

```text
Time  → O(N)
Space → O(N)
```

# 27. Important Java Note — Strings

Java `String` is immutable.

So repeatedly doing:

```java
return current + rest;
```

may create additional strings and can affect practical performance.

For learning recursion, this is fine.

For production code, depending on the problem, consider:

```java
StringBuilder
```

or another approach.

The important thing here is understanding the recursive state, not optimizing string construction yet.

# 28. Common Mistakes

## Mistake 1 — Wrong Base Case

Wrong:

```java
if (index == arr.length - 1)
    return;
```

when you still need to process the last element.

Be clear about whether the base case means:

```text
"We have reached the last element"
```

or:

```text
"We have gone past the last element."
```

---

## Mistake 2 — Index Goes Out of Bounds

Wrong:

```java
arr[index]
solve(index + 1)
```

without stopping when:

```text
index == arr.length
```

---

## Mistake 3 — Confusing Current and Remaining Work

Remember:

```text
arr[index]
```

is the **current element**.

```text
solve(index + 1)
```

handles the **remaining elements**.

---

## Mistake 4 — Forgetting Return Values

Wrong:

```java
max(arr, index + 1);
```

if you need the result.

Correct:

```java
int answer = max(arr, index + 1);
```

---

## Mistake 5 — Not Understanding Before vs After

These are different:

```java
System.out.println(arr[index]);
solve(index + 1);
```

vs:

```java
solve(index + 1);
System.out.println(arr[index]);
```

The first processes while going down.

The second processes while coming back up.

# 35. Golden Rules

> **Rule 1:** Treat the index or pointers as the recursive state.

> **Rule 2:** Define exactly what your recursive function means before coding.

> **Rule 3:** `index` usually represents the current position.

> **Rule 4:** `index + 1` means "let recursion handle the remaining elements."

> **Rule 5:** `left + 1, right - 1` means "solve the inner range."

> **Rule 6:** Work before recursion happens while going down.

> **Rule 7:** Work after recursion happens while coming back up.

> **Rule 8:** Always make sure your index moves toward the base case.

> **Rule 9:** When every element creates choices, you are moving toward multiple recursion/backtracking.

# 36. One-Line Summary

> **Array and string recursion means representing the unsolved portion of the data using an index or range, solving the current part, and trusting recursion to handle the remaining part.**

### Core Mental Model

```text
              solve(index)
                   |
                   ↓
             current element
                   |
                   ↓
            smaller remainder
                   |
                   ↓
            solve(index + 1)
                   |
                   ↓
              final answer
```

For two pointers:

```text
             solve(left, right)
                    |
                    ↓
              current pair
                    |
                    ↓
          solve(left+1, right-1)
                    |
                    ↓
                 answer
```

**Next major transition:**

```text
Arrays & Strings
       ↓
Decision at each element
       ↓
Multiple Recursion
       ↓
Subsets / Subsequences
       ↓
Backtracking
```
