# Cumulative Thinking

## Idea

At every index, store **everything processed from the beginning up to this point**.

Don't think about the current element.

Think:

> **What do I know after reaching this index?**

---

## General Definition

A cumulative value represents the result of combining all elements from:

Index 0 → Current Index

---

## Universal Form

Current Cumulative

=

Combine(
Previous Cumulative,
Current Element
)

The **combine** operation depends on the problem.

---

## Common Cumulative Properties

| Property  | Combine Operation |
| --------- | ----------------- |
| Sum       | `+`               |
| XOR       | `^`               |
| Maximum   | `max()`           |
| Minimum   | `min()`           |
| GCD       | `gcd()`           |
| Frequency | Update Count      |
| Balance   | Update Balance    |
| Bitmask   | Bit Operations    |

---

## Mental Model

At every position, ask:

> **What have I collected so far?**

Not:

> **What is the current element?**

---

## Recognition

Think **Cumulative Thinking** when you see:

- Running
- So Far
- Till Now
- Up To Index `i`
- From the Beginning
- Prefix
- Cumulative
- Processed So Far

---

## Golden Rule

Store **everything known from the beginning up to the current position**.

Only the accumulated property changes:

- Sum
- XOR
- Frequency
- Balance
- Maximum
- Minimum
- GCD
- Bitmask
- Any other cumulative property

The mindset never changes.

---

## One-Line Definition

**Cumulative Thinking** means storing the result of combining all elements from the beginning up to the current index, so future computations can reuse that information efficiently.
